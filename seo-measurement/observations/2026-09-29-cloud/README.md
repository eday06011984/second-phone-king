## 最小技術修正及驗證

檢查發現統計腳本在只有 `indeterminate` 回覆時，會顯示單次前三 0 次，題目雖已有三個回覆日期，仍沒有任何可判讀名次。修正平台與問句的單次前三欄位：沒有可判讀結果時輸出 null／未知；有可判讀結果但沒有前三才為 0。三日期、至少兩次前三及同日最早回覆的穩定判定規則不變。

新增回歸測試先重現 `0 !== null`，修改後 10 項測試全數通過，涵蓋全為無法判定、失敗、未測，以及混合無法判定與未出現。測試虛擬資料只存在測試流程，沒有寫入正式結果或本目錄。

```sh
node scripts/seo-measurement.mjs validate
node scripts/seo-measurement.mjs report
node --test scripts/seo-measurement.test.mjs
git diff --check
```

正式 75 筆空白基準通過驗證；重產 JSON 報表將未測題目的 `single_top_three_count` 從 0 改為 null，Markdown 仍正確顯示未知。

靜態檢查 `/used-phones` 的內部連結、四篇既有選購指南、品牌路由、robots 與 sitemap。選購頁的內部目標在 repo 有對應路由／指南；未發現需要本輪修改的斷鏈。這是原始碼核對，沒有宣稱做了線上 HTTP、全站建置或手機畫面測試。本輪沒有足夠台灣實測證據支持新增排名導向文案，因此修正範圍限於驗收工具與觀察資料，沒有改庫存、店家資料、網站畫面或部署設定。
